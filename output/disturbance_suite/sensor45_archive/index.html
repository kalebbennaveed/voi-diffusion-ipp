Clarity is a monitoring-quality index between 0 and 1. The target is 0.75. Cost is the time integral of the mean positive shortfall below that target, over all monitored cells; lower is better. Both methods optimize all nominal acceleration coordinates with MBD, using the same geometry and search budget. Aware planning predicts wind-affected, filtered execution. Blind planning predicts nominal motion with zero wind and no filter intervention; its simulated flight uses the same wind-informed controller and filter. This tests the combined disturbance-and-filter-aware execution prediction. Beliefs remain fixed within each planning call.
