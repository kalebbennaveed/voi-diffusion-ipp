HOW TO READ THIS REPLAY

Reference → real dynamics

The solid coloured trail is the executed quadrotor motion. The dashed white segment is the current double-integrator reference. Each inset shows the actual simulated attitude at physical vehicle scale.

All three methods share the same vehicle, wind field, initial belief and sensor-noise sequence. All methods start with the same ten noisy preflight wind measurements on B/C; passage A is unmeasured. Actual measurements update the estimator in every method. Only the proposed planner anticipates those updates inside its predictions.

Model, controller and experiment details

The planner uses the existing MBD score update and sampled policy-value control filter. Its route policy chooses an inspection region, separate outward and return passages, cruise speed and dwell time; hypothetical observations affect subsequent feedback controls. This is a restricted policy class, not an unrestricted trajectory optimum.

The 22-state plant includes 3D position and velocity, rotation on SO(3), body angular velocity and four motor speeds, with motor lag, drag and rotor angular momentum. A geometric tracker follows quintic flat-output references. All methods use a ±2.6 m/s² commanded horizontal thrust-per-mass envelope; aerodynamic compensation consumes the same finite authority. There is no added PLCBF controller.

Moving wind tracers show a synthetic spatial air-velocity field. The plant uses quadratic drag relative to that air velocity. This is a reproducible disturbance experiment, not a CFD simulation. POAM uses a full sparse predictive covariance with fixed kernel and inducing locations for these runs. Planner field tables are sampled on a 1 m grid.
