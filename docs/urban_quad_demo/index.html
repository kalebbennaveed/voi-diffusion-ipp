HOW TO READ THIS REPLAY

Reference → real dynamics

The solid coloured trail is the executed quadrotor motion. The dashed white segment is the current double-integrator reference. Each inset shows the actual simulated attitude at physical vehicle scale.

All three methods share the same vehicle, wind field, initial belief and sensor-noise sequence. Actual measurements update the estimator in every method. Only the proposed planner anticipates those updates inside its predictions.

Model, controller and experiment details

The planner uses the existing MBD score update and sampled policy-value control filter. Its route policy chooses an inspection region, passage, cruise speed and dwell time; hypothetical observations affect subsequent feedback controls. This is a restricted policy class, not an unrestricted trajectory optimum.

The 22-state plant includes 3D position and velocity, rotation on SO(3), body angular velocity and four motor speeds, with motor lag, drag and rotor angular momentum. A geometric tracker follows quintic flat-output references. All methods share the planner’s ±2.6 m/s² compensated horizontal command envelope; known drag compensation is retained. There is no added PLCBF controller.

Wind arrows show a synthetic spatial acceleration load applied as an external force. This is a reproducible disturbance experiment, not a CFD simulation. POAM uses a full sparse predictive covariance with fixed kernel and inducing locations for these runs. Planner field tables are sampled on a 1 m grid.

Drone geometry: autonomous-drone-racing-local (MIT). Building style: fastpathplanning Village (Apache 2.0), rearranged to the supplied layout. Dynamics/tracker: lab-experiment-sim-starter (MIT).
